## Elevator Pitch

> 4つの役割と合成魔法で、魔物の大群と巨大ボスを討つローポリのファンタジーFPS。
> 1人では役割を切り替えて戦い、協力では役割を分担して魔法を合成する。

## Core Fantasy

「付与 → 切り替え → 起爆」で、作戦がはまった瞬間に大群がまとめて吹き飛ぶ。
例: 術士の氷で凍らせる → 守護者に切り替える → 3段目の一撃で砕氷が決まり、敵が砕け散る。

## Unique Hook

1人で4つの役割を切り替えて「自分ひとりで連携する」。協力では同じ合成を仲間と同時に決める。
1人用のAIの仲間を作らずに、1人でも協力でも成立する。

---

## Core Loop

- **数秒**: 状態を付ける → 役割を切り替える → 合成で起爆する。
- **1部屋（約2分）**: ウェーブを3つしのぎ、ルーンを3つから1つ選ぶ。
- **1回の出撃（25〜30分）**: 3エリア × 部屋5〜6個 → 各エリアのボス。
- **長期**: 拠点でルーンの候補を増やし、侵食度（難易度0〜10）を上げる。

---

## Game Pillars

1. **合成が主役**: 単純に撃ち続けるより、合成を狙う方が明らかに強い（合成は元の攻撃の3〜5倍）。
2. **1人でも協力**: 1人用と協力用で別のシステムを作らない。
3. **読める画面**: くすんだ世界に、魔法だけが鮮やか。大群の中でも何が起きたか一目で分かる。

### Anti-Pillars

- 1人用のAIの仲間は作らない。
- 恒久強化で数値を積み上げるゲームにはしない（拠点の強化は主に選択肢が増える形）。
- ムービーで物語を語らない。

## 戦闘と操作

数値は最初の目安です。基準は術士の通常弾1発＝30、プレイヤーの体力＝500。
プロトタイプの数値は `Assets/RuneBrigade/` のScriptableObjectで調整します。

### 基本操作（PC）

| キー | 動作 | 補足 |
| --- | --- | --- |
| WASD、Space | 移動、ジャンプ | 移動は速め |
| Shift | ダッシュ回避 | 2回までストック、1回分の回復は3秒、0.2秒の無敵 |
| 左クリック | 通常攻撃 | 役割ごとに違う |
| 右クリック | サブ動作 | ガード、属性切替、照準など |
| Q、E | スキル1、スキル2 | 役割ごとに個別のクールダウン |
| R | 奥義 | 攻撃・合成・被ダメージで溜まるゲージ式 |
| 1〜4 | 役割の切り替え | 1人プレイ時 |
| F | 蘇生、調べる | |

### 状態と合成のルール

- 合成は、状態を持つ敵に対応する攻撃が当たると発動し、その状態は消費される。
- 1体に付く状態は最大2つ。新しい状態を付けると古い方から消える。持続は基本4秒。
- ボスには状態耐性ゲージがあり、何度も当てないと状態が付かない。
- 合成のダメージは元の攻撃の3〜5倍。

| 先に付ける状態 | 後から当てる攻撃 | 合成 | 効果 |
| --- | --- | --- | --- |
| 集結（守護者） | 隕石（術士） | 殲滅 | 集めた敵がまとめて吹き飛ぶ |
| 凍結（術士） | 溜め撃ち（狩人）、守護者の3段目 | 砕氷 | 大ダメージ |
| 帯電（術士） | 盾ガード（守護者） | 反射雷 | 受けた攻撃を雷にして返す |
| 打ち上げ（守護者） | 拡散矢（狩人） | 空中処刑 | 浮いた敵にクリティカル確定 |
| 聖化結界（祈祷師） | 矢が結界を通過（狩人） | 聖矢 | 貫通し、アンデッドに特効 |
| 増幅（祈祷師） | 任意の奥義 | 奥義・倍化 | 範囲と威力が2倍 |
| 炎上＋帯電（術士） | ― | 爆雷 | 連鎖爆発 |

### 役割の切り替え

- 切り替えは0.4秒。使っていない役割のクールダウンも進む。
- スイッチストライク: 切り替えて2秒以内の最初の攻撃は威力+50%。
- 体力はプレイヤーで1本。切り替えると最大体力の倍率だけ変わり、残りの割合は維持される。

| 人数 | 役割の持ち方 |
| --- | --- |
| 1人 | 4つ全部を切り替え |
| 2人 | 出撃前に2つずつ選ぶ（重複なし） |
| 3人 | 1人1つずつ。残りの1つは誰でも切り替えて使える |
| 4人 | 1人1つで固定 |

### 手ごたえ

| 要素 | 内容 |
| --- | --- |
| ヒットストップ | 通常攻撃30ミリ秒、守護者の3段目80ミリ秒、合成120ミリ秒 |
| スロー演出 | 合成の発動時に0.2秒だけ時間の流れを30%に |
| 画面の揺れ | 守護者と隕石は強め、狩人は揺らさない |
| ヒットマーカー | 通常は白、弱点は翠、合成は2色の破片 |
| 敵の反応 | 怯む、吹き飛ぶ、ラグドールになる |
| 音 | 着弾音を「軽い・重い・合成」の3段階に分ける |

### Formulas

```
敵の体力倍率 = 1 + 0.6 × (人数 − 1)
敵の数の倍率 = 1 + 0.4 × (人数 − 1)   （出現数は四捨五入、元が1以上なら最低1）
1ヒットのダメージ = 基礎ダメージ × 弱点倍率 × スイッチストライク倍率 × 合成倍率
```

- 協力では倒れてから30秒以内に仲間が蘇生できる。1人プレイでは出撃ごとに1回だけ自動で復活する。
- 協力で別々のプレイヤーが合成を決めると、両者の奥義ゲージが多めに溜まる。

## 敵とボス

### 設計の原則

1. 役割ごとの「楽に倒せる答え」を必ず用意する。
2. 攻撃の前に0.6〜1.0秒の予兆を出す。地面に侵食の暗い紫で範囲を表示し、当たる直前に明るくする。
3. 同時に攻撃できる敵を制限する。近接は3体、遠距離は2体まで（攻撃権トークン方式）。
4. 群れる、一列に並ぶ、止まるなど、合成を狙いやすい瞬間を敵の側から作る。

### 雑魚

| 敵 | 体力 | 行動と攻撃 | 楽に倒せる役割 |
| --- | --- | --- | --- |
| 群れゴブリン | 60 | 5〜8体で突っ込む。引っかき25 | 術士の範囲魔法 |
| 骸骨兵 | 200 | 正面を盾で防ぐ。突き50（予兆0.8秒）の後に1秒の隙 | 守護者のジャストガード、狩人の背後狙い |
| 飛行コウモリ | 40 | 照準中のプレイヤーを狙って急降下。噛みつき20と照準の揺れ | 狩人の拡散矢、祈祷師の光線 |
| 呪術師 | 150 | 後方で味方を回復・強化し、近づくと瞬間移動で逃げる | 狩人の狙撃 |
| 重装オーガ | 1200 | 振り下ろし120（予兆1.0秒）、薙ぎ払い80。半分で怒って速くなる | 凍結させて狩人の溜め撃ち（胸が弱点） |
| 膨れ虫 | 30 | 足元で自爆。範囲3mに100。倒すと爆発して周りの敵を巻き込む | 遠くから撃つ |

### エリートの性質（エリア2以降）

体力は2倍で、倒すとルーンの選択肢が1つ増える。

| 性質 | 効果 | 答え |
| --- | --- | --- |
| 霊体 | 通常の攻撃が半分しか効かない | 祈祷師の聖化 |
| 分裂 | 倒すと小さい個体が2体出る | 範囲魔法 |
| 俊足 | 移動と攻撃が1.5倍速い | 狩人の拘束 |
| 反射 | 魔法を一部はね返す | 守護者・狩人の物理攻撃 |

部屋のウェーブは「爽快（ゴブリンの群れ）→ 考える（骸骨兵）→ 両方（オーガ＋呪術師＋ゴブリン）」の順に並べる。

### ボス

| ボス | エリア | 体力（1人） | 戦闘時間 | 攻略の軸 |
| --- | --- | --- | --- | --- |
| 石の巨人「グラム」 | 1 | 18,000 | 約3分 | 両足を攻撃して膝をつかせ、胸のコアが10秒露出した間に撃つ |
| 腐竜「ネクロワイバーン」 | 2 | 24,000 | 約4分 | 翼を撃って墜落させると、15秒間地上で攻撃できる。聖化が特効 |
| 双頭の魔術師「ヴァル＝シェラ」 | 3 | 30,000 | 約5分 | 炎と氷の頭が交代し耐性が入れ替わる。双頭の詠唱は3秒以内の爆雷で潰す |
| 空白（ナナシ） | 最奥 | 未定 | 未定 | プレイヤーが集めたルーンを奪って使ってくる |

- **グラム**: 第1段階（100〜60%）は踏みつけ、岩投げ（ジャストガードで投げ返すとコアに直撃）、膝つき。第2段階（60〜20%）は岩の兵の召喚と回転なぎ払い。第3段階（20%〜）は崩れながら暴れ、コアが常に露出する。
- **ネクロワイバーン**: 空中では腐敗のブレス、急降下（ジャストガードで墜落）、骨の雨（結界に避難）。地上では噛みつきと尻尾。体力30%以下で霊体の雑魚を大量に呼ぶ。
- **ヴァル＝シェラ**: 炎の頭が主導のときは氷が2倍効き、氷の頭が主導のときは炎が2倍効く。体力40%以下で頭が10秒ごとに交代し、交代の直後が一番脆い。

## ルーンとローグライト

### 出撃の流れ

1. 拠点（旅団の野営地）から出撃する。
2. エリア1「霧の森と廃村」: 部屋5〜6個のあと、ボス「石の巨人」。
3. エリア2「沈んだ地下墓所」: 部屋5〜6個のあと、ボス「腐竜」。
4. エリア3「浮遊する古代遺跡」: 部屋5〜6個のあと、ボス「双頭の魔術師」。
5. クリア後に最奥が解放され、最終ボス「空白」に挑める。

部屋は分岐するマップで進み、次の部屋の種類がアイコンで見える。

| 部屋 | 内容 | 出やすさ |
| --- | --- | --- |
| 戦闘 | ウェーブ戦。クリアでルーンを3つから1つ | 多い |
| エリート | 強化個体が出る。希少以上のルーンが確定 | 普通 |
| 泉 | 体力回復か、ルーン1つの強化 | 1エリアに1回 |
| 行商人 | 魔石でルーン、回復薬、引き直し券を買う | 1エリアに1回 |
| 祭壇 | ルーンを別のルーンに変える。呪いルーンを受け取れる | まれ |
| 出来事 | 選択肢つきの小さなイベント | 普通 |

### ルーンの仕組み

- **役割ルーン**はその役割の武器に刻み、使っている間だけ効く。**旅団ルーン**は全役割に効く。
- スロットは、1人では役割ごとに2つ＋旅団4つ。協力では自分の役割ごとに3つ＋旅団4つ。
- 希少度は通常（白）、希少（役割の色）、伝説（金の縁取り、1回の出撃で1〜2個）、呪い（侵食の紫）。
- 選択肢は今の役割と持っているルーンに寄せて出やすくする。魔石で引き直せ、値段は回数ごとに上がる。

### 共鳴

特定のルーンを2つ揃えると共鳴して追加効果が出る。最初は名前が隠れていて、見つけると書庫に記録される。

| 組み合わせ | 共鳴 | 追加効果 |
| --- | --- | --- |
| 永久凍土＋鋭い鏃 | 氷晶の狩り | 砕氷の破片が周りに刺さり、凍結を広げる |
| 引力の咆哮＋降り注ぐ星 | 天墜 | 【集結】中の敵の上に必ず隕石が落ちる |
| 光の糸＋一矢必中 | 聖なる一閃 | 貫通する矢が通った味方を回復する |
| 早替え＋共鳴打 | 流転 | 4役割を順に切り替えると、次の攻撃が全属性の合成になる |

### 拠点と侵食度

| 施設 | 内容 |
| --- | --- |
| 鍛冶台 | 遺物の欠片で新しいルーンを候補に追加（24個から最終80個程度） |
| 書庫 | 敵、合成、共鳴の図鑑。見つけると自動で記録 |
| 焚き火 | 小さな恒久強化（体力+5%など、上限あり） |
| 見張り台 | 侵食度（難易度0〜10）の設定。ボス撃破で解放 |
| 天幕 | 武器や衣装の見た目の変更 |

侵食度はクリアするたびに1段階ずつ上げられ、段階ごとに不利な条件が1つ増えて報酬も増える（例: 1＝敵の体力+20%、5＝泉の回復量が半分、10＝最終ボスが2体のルーンを奪う）。

### 1人と協力の違い

- 協力では各自がルーンを3つから1つ選び、魔石は仲間に渡せる。
- 協力専用の「絆」ルーンが出る（例: 近くの味方と同じ敵を攻撃するとダメージ+20%）。
- 呪いルーンは誰が受けるかを相談でき、仲間の分を肩代わりできる。

## 世界観とストーリー

世界のすべてはルーン（名前の文字）で書かれていて、その名前を喰らう「空白」によって世界から色と形が失われつつある。旅団は喰われた名前を取り戻すために進む。

### 設定とゲームの仕組みの対応

| 設定 | ゲームでの意味 |
| --- | --- |
| 名前が薄れ、世界から色が失われている | 世界が低彩度な理由 |
| 魔法は今まさに書かれているルーン | 魔法だけが鮮やかな理由 |
| 魔物は名前を喰われたもの。紫の紋様は読めなくなったルーン | 敵の侵食の見た目 |
| 魔物を倒すと名前の欠片が解放される | 敵を倒すとルーンが手に入る理由 |
| 「名の灯」が持ち主の名前を書き残している | 倒れても野営地で目覚める理由 |
| 侵食された土地は名前が不安定 | 行くたびにマップが変わる理由 |
| 1人で出撃する主人公は4つの根源ルーンを宿せる「灯の担い手」 | 1人で役割を切り替えられる理由 |
| 空白は名前が欲しくてルーンを喰らう | 最終ボスがプレイヤーのルーンを奪う理由 |

### 四つの根源ルーン

| 役割 | 根源ルーン | 意味 |
| --- | --- | --- |
| 守護者 | 守（まもり） | 留め、引き寄せ、支える |
| 術士 | 変（かわり） | 物の在り方を書き換える |
| 狩人 | 射（いぬき） | 隠されたものを見抜き、貫く |
| 祈祷師 | 結（むすび） | 名前と名前をつなぎ、癒やす |

### エリアとボスの物語

| エリア | かつての姿 | ボスの正体 |
| --- | --- | --- |
| 霧の森と廃村 | 旅団の始まりの村。今は「霧」のルーンだけが残る | 村を守る石の番人グラム。「守れ」という命令だけが残った |
| 沈んだ地下墓所 | 死者の名前を刻んで弔う聖なる墓所 | 死者の名前を空へ送る「送り竜オルヴァン」。名前を喰われ死を運ぶ腐竜になった |
| 浮遊する古代遺跡 | 世界を書いた書き手たちの都「原初の書庫」 | 双子の賢者、炎の兄ヴァルと氷の妹シェラ。禁術に失敗し1つの体に溶け合った |

最終ボス「空白（ナナシ）」は、世界が書かれたときにただ一つ名前を与えられなかった余白。

- 通常エンディング: 空白を倒して封印し、世界に色が戻り始める。
- 真エンディング（侵食度を上げてクリアで解放）: 4つの根源ルーンを合わせて空白に名前を与える。

## Technical Considerations

| 項目 | 方針 |
| --- | --- |
| 描画 | URP。Color GradingとBloom、Shader Graph、VFX Graph |
| ネットワーク | FishNet か Netcode for GameObjects（未決定）。Steamのリレーでサーバー費用をかけない |
| 数値 | 役割、敵、ボス、ルーンはすべてScriptableObject |
| 合成 | 「状態 × 攻撃 → 合成」の対応表データ。コードに直接書かない |
| ルーン | 攻撃が当たった、状態を付けた、合成が決まった、役割を切り替えた、敵を倒した、などのイベントに反応する仕組み |
| 敵AI | NavMeshAgent＋ステートマシン。攻撃権トークンを管理するクラスを1つ置く |
| マップ | 部屋のテンプレート10〜15種類をランダムに並べる |
| 構成 | 1人プレイ＝ホスト1人のマルチプレイとして作る。ゲームの規則はUnityに依存しないコア（`RuneBrigade.Core`）に置く |

## MVP Definition（最初のプロトタイプ）

検証すること: **1人で役割を切り替えて合成を決めるのが気持ちいいか**。

| 要素 | 内容 |
| --- | --- |
| 役割 | 守護者と術士の2つ（切り替えあり） |
| 合成 | 殲滅（集結＋隕石）、砕氷（凍結＋守護者の3段目）、爆雷（炎上＋帯電）、反射雷（帯電＋ジャストガード） |
| 敵 | ゴブリン、骸骨兵、オーガ |
| ステージ | アリーナ1つでウェーブ制 |
| 演出 | ヒットストップ、合成時のスロー、画面の揺れ、合成名の表示 |
| 協力 | この段階ではオフライン。ネットワークを組み込める設計にだけしておく |

コード: `Assets/RuneBrigade/`。Unityでの組み立て手順: [docs/prototype-unity-setup.md](../docs/prototype-unity-setup.md)。
